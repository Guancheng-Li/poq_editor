# 常用命令
# 每一行一个命令，格式为：{命令}#{显示名称}；
# 如果不含显示或显示部分为空，则直接显示命令；
# 如果含多个“#”命令和显示名称用第一个“#”分割；

# GM命令参考
# https://tieba.baidu.com/p/6871382785
# https://tieba.baidu.com/p/1722491389
# https://tieba.baidu.com/p/9343982968

# 查看类
look#显示本场景信息（包含出入口、NPC、物品等）
dir#显示出入口


# 状态类
godblessme#进入无敌状态（切换场景后失效，需重新输入）


# 加点类
# 人名通过本工具属性修改“别名”处可获得
c_c Str 100#加100点力量
c_c Con 100#加100点体质
c_c Dex 100#加100点敏捷
c_c Savvy 100#加100点悟性
c_c Charm 100#加100点魅力
c_c Wisdom 100#加100点智慧
c_c Fame 100#加100点声望
c_c Money 999999#加999999金线
c_c Extra_Skill 100#加100点未分配技能点
c_changeint Extra_Exp 1000#加1000点未分配属性点
# 以下内容以孔刚为例，改成其他人也行，名字见本工具属性修改里的别名
# 省略konggang的话单人游戏给扶苏加，多人游戏给自己加
exp konggang 1000#给孔刚增加1000点经验
# 加多了可以减少
c_c Charm -1#减1点魅力


# 移动类
#summon [某人]#将[某人]传送到自己的身边(无需对方同意)，可以用look查看人名
#after [某人]#将自己传送到[某人]的身边(无需对方同意)，可以用look查看人名
goto 秦殇/咸阳/ROOM/杂货铺#传送到咸阳杂货铺（单人游戏）
goto 秦殇/NET/阳周城#传送到阳周城（多人游戏）
goto 秦殇/NET/汉中郡
goto 秦殇/NET/邯郸
goto 秦殇/NET/陈城
goto 秦殇/宛城/ROOM/尉缭子家地下密室
goto 秦殇/阿房宫/ROOM/胡亥寝宫
goto 秦殇/骊山/ROOM/始皇陵外城
goto 秦殇/咸阳/ROOM/赵高地宫一层


# 获取类
get all#获取地图内所有物品，包括隐藏的
#get [物品名]#获取特定物品，通过look查找
kill all#（慎用）杀死地图内所有人物
#kill [物品名]#杀死特定人物，包括NPC，通过look查找
destroy [物品名]#破坏物品，用于开宝箱或者毁坏隐藏道具
