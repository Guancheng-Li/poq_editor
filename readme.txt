========================================
  秦殇修改器 (PoqEditor) - imgui 版
========================================

【这是什么】
秦殇(POQ)游戏内存/存档修改器。单文件版免安装、免依赖,拷贝即用。
自动识别游戏版本:EasyRPG.dll = Steam 版,EasyRPG116.dll = v1.30 版。

【本目录文件】
  PoqEditor.exe   主程序(双击运行,自动请求管理员权限)
  readme.txt      本说明
  gm_cmd.txt      GM 命令参考(GM 命令 tab 的命令列表来源)
  data\           装备目录/物品名等数据文件

【主界面 tab】

■ 人物修改
  - 初始化后自动读取队伍成员;修改生命/精气/六维/五系攻防/闪避/命中/经验/声望/视野等。
  - 保存后存档再读档生效;可勾选"无敌模式/一击必杀"实时锁定。
  - 视野字段可直接改,但**运行中改写可能导致游戏异常**,建议改存档或配合装备词条。

■ 道具修改
  1. 游戏中鼠标选中箱中物品后放下(读取最后选中的物品,不是光标上的)。
  2. 点"读取属性"载入基础属性与词条列表。
  3. 基础属性可改(等级/鉴定/耐久/价格/重量/类型/孔数/需求/五行/弓箭数量;
     类型 13 箭/14 矢时孔数与耐久强制处理);名字/别名/ID 只读。
  4. 词条列表:添加/删除/勾选删除/类型下拉(白蓝亮蓝金),支持"复制上一件物品"、
     JSON 模板导入导出。词条新增走动态内存池,上限 128 条。
  5. "保存属性"写回内存;物品扔地上再捡起生效。

■ 召唤修改
  - 按游戏版本自动选 Steam / v1.30 逻辑,二者完全隔离。
  - mon_type(野兽 0-9)/assassin_type(刺客)/soldier_type(秦兵 0-6 大类×子类)、
    group 0=队友可控 1=盟友不可控。
  - 地址全部运行时定位(模块基址+偏移+入口自检),免疫 ASLR;每次启动都能用。
  - 1.30 版暂未经完整回归测试,遇到问题优先报告。

■ GM 命令
  - 游戏控制台命令的快捷发送;命令列表来自 gm_cmd.txt(格式: 命令#显示名)。
  - 自定义命令直接在输入框输入发送。

■ H2 解密
  - H2 格式文件(如 .qed)加解密预览,自动备份 .dec/.enc.bak,原子替换。

■ gam 修改(存档文件级,最强也最需谨慎)
  - 打开 .gam 存档直接编辑:地图→房间→物品树;非装备记录(技能等)只读。
  - 基础字段/词条编辑与"道具修改"同款;词条数组直读写记录尾部,
    支持新增词条立即生效(不用先进游戏捡物品)。
  - 全装备目录按"类别→名字"**创建新物品**(自动落位坐标,可拾取);
    物品/属性复制粘贴、JSON 模板导入。
  - 保存时自动把内容补回原长,避免"内容变短→地上物品消失"。
  - 打开自动留 .bak 备份;退出时按 MD5 清理**未改动**的备份(可选是/否/取消)。
  - 详细使用说明见程序内"帮助"(与主界面 tab 同名联动)。

■ 内存查看 / 偏移设置(调试 tab,默认隐藏)
  - 开发调试用,常规修改用不到。

【通用注意】
- 必须管理员运行,否则初始化报"OpenProcess 失败"。
- 内存修改(道具/人物)需存档读档或扔捡物品才落盘生效;
  gam 修改是直接改存档文件,改前请关闭游戏或确保不在该存档内。
- 程序版本号 = 编译日期(启动弹窗 Ver: YYMMDDvN)。
