========================================
  秦殇物品修改器 (PoqEditor) - 单文件版
========================================

【这是什么】
秦殇(POQ)游戏内存修改器。单文件版免安装、免依赖,拷贝即用。

【本目录文件】
  PoqEditor.exe   主程序(双击运行,会自动请求管理员权限)
  readme.txt      本说明

【使用方法】
1. 启动游戏(POQ.EXE)。
2. 双击 PoqEditor.exe(会自动请求管理员权限并启动)。
3. 顶部"选择进程"下拉框选 POQ.EXE,点"初始化"。
4. 在游戏中用鼠标拾起要修改的物品(保持在光标上)。
5. 点"读取属性",载入该物品的基础属性与属性列表。
6. 修改基础属性;属性列表可"添加/删除/清空"条目,或"从模板读取"载入
   JSON 模板,也可"另存为"导出当前属性为 JSON。
7. 点"保存属性"写回游戏内存。
8. 回到游戏,把物品扔到地上再捡起,修改即生效。

【基础属性说明】
- 武器名字、武器别名、武器ID 为只读,不可修改。
- 武器等级、是否鉴定、耐久度、耐久度上限、基准价格、重量、类型、孔数、
  等级/力量/敏捷/体质需求、五行、弓箭数量 可按需修改。
- 类型为 13(箭)/14(矢) 时:孔数强制为 0、耐久度/上限强制为 -1,
  弓箭数量仅此时可编辑。

【注意】
- 必须以管理员身份运行,否则初始化会报"OpenProcess 失败"。
- 修改后必须把物品扔到地上再捡起才会生效。
- 属性列表新增条目受数量限制,满时无法新增(会提示)。
